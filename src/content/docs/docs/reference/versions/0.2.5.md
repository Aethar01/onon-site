## Configuration options

Assign options with `gopdf.options.<name> = <value>` in Lua or `:set <name>=<value>` at runtime. Colors use `{ r, g, b }` in Lua and `r,g,b` or `#RRGGBB` with `:set`.

## Commands

| Command | Description |
|---|---|
| <code>:colors normal&#124;alt</code> | Set color mode |
| <code>:fit width&#124;page&#124;manual</code> | Set fit mode |
| <code>:help</code> | Show this command help window |
| <code>:keybinds</code> | Toggle the keybinds menu |
| <code>:lua &lt;code&gt;</code> | Execute Lua code inline |
| <code>:mode continuous&#124;single</code> | Set render mode |
| <code>:open &lt;filename&gt;</code> | Open another PDF relative to the current document |
| <code>:open_file_picker</code> | Open the PDF file picker |
| <code>:page PAGE, :p PAGE, :N</code> | Jump to a page number or label |
| <code>:quit, :q</code> | Exit |
| <code>:reload-config</code> | Reload the config file |
| <code>:recent</code> | Open the recent-files menu |
| <code>:search [-r] [-i] [-w] [-p] &lt;text&gt;</code> | Search document text |
| <code>:set [option[?]&#124;option!&#124;option=value]</code> | Inspect or change options |

Search flags: `-r` regular expression, `-i` ignore case, `-w` whole word, and `-p` current page only. Flags can be combined.
